# Decision Rubric — scoring manual

Score the brief /100. For every deduction cite the exact line. The score is directional (Pass / Borderline / Revise), not a calibrated instrument — do not read small gaps as verdicts.

## Dimensions

### 选项充分性 /20

- 18-20：>= 3 个真选项，每个都有「理性人理由」；「不做」被认真评估过（有预期结果和概率，不是一行敷衍）。
- 12-17：选项数够但有一个偏弱；或「不做」只被口头提及。
- 6-11：两个真选项 + 陪跑项；选项间差异是执行细节而非方向。
- 0-5：单选项包装成多选项（fatal 联动）。

### 证据强度 /20

- 18-20：载重主张全部 F1 以上；关键 F2 已核或有核实计划；无裸 F3。
- 12-17：F 标签齐全但 1-2 条载重 F2 未核且无计划。
- 6-11：标签不全，或关键主张依赖单一来源。
- 0-5：关键证据是传闻（fatal 联动）。

### 对立面强度 /20

- 18-20：红队从 steelman 出发；至少 2 条反对意见在修订后仍然成立并写进备忘录。
- 12-17：有红队但攻击面窄（只攻证据，没攻框架/激励/时机）。
- 6-11：红队走过场——反对意见全被「解释掉」，一条都没改变 brief。
- 0-5：稻草人反方（fatal 不触发，但本维度记 0 并点破）。

### 失败预案与止损位 /15

- 13-15：止损位=可观察事件+owner+动作；premortem 产出已转成触发器。
- 8-12：有止损位但表述模糊（「如果效果不好」）。
- 0-7：无止损位（fatal 联动）或纯装饰。

### 利益相关方覆盖 /15

- 13-15：受影响方列全；建议/拍板/执行三权明确（一个拍板人，不是委员会和稀泥）。
- 8-12：列了人但决策权归属含糊。
- 0-7：只见「我」，看不见谁被影响、谁能否决。

### 时机判断 /10

- 9-10：「为什么是现在」有具体答案；等待的成本和新信息的价值被显式比较。
- 5-8：有时限但没论证。
- 0-4：时限缺失，或「现在就要决定」经不起一句追问。

## Fatal issues（任一命中 -> Revise，与分数无关）

1. 只有一个真选项（稻草人 slate）
2. 关键证据 F3 无源，或载重 F2 未核实**且无带前置条件的核实计划**（「承诺前核不完 X 则自动落选项 Y」算合格计划——有计划扣分不 fatal）
3. 无止损位
4. Type 1 决策**到出备忘录阶段**仍未跑 premortem（premortem 前的初评 scorecard 不触发此条）
5. 结论先行且用户不认（标注后继续，但记 fatal）

## Verdict bands

- **Pass**：无 fatal 且各维清晰扎实（粗略 ~85+）
- **Borderline**：无 fatal，1-2 个维度明显偏弱 -> 只修最弱维，复评
- **Revise**：任一 fatal，或整体明显薄弱

每张 scorecard 标注 loop 计数与阶段：`QA loop N/2 · 初评` / `QA loop N/2 · 复评`（同一轮的初评复评共用同一 N，见 SKILL.md）。2/2 后 Graceful Halt：输出最佳版本 + 未解决缺口清单，交还用户。
